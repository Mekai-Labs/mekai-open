# Contributing

Issues, adversarial fixtures and focused pull requests are welcome.

1. Discuss material contract changes in an issue first.
2. Keep the core read-only, deterministic and transport-neutral.
3. Preserve exact input provenance and explicit missingness.
4. Add an independent truth fixture for every product-function semantic change.
5. Run the complete test suite before opening a pull request.
6. Sign off commits with `git commit -s` to certify the Developer Certificate of Origin.

By contributing, you agree that your contribution is licensed under AGPL-3.0-only.
